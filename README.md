### 😊 [Smile](https://github.com/vitorbetmann/smile) — 2D Game Development Library:
An open-source, modular C library to streamline common 2D game dev tasks such as managing scenes, simulating particles, and saving/loading. Ideal for quick prototyping (see games [made with Smile](https://github.com/vitorbetmann/made-with-smile)) and supported on macOS, Windows, and Linux.

### 🐮 [Joanna's Diner](https://github.com/vitorbetmann/joannas_diner) — Cooking Game:
Built core gameplay systems such as food crafting, inventory, and customer behavior, but I'm most proud of creating a custom Unity editor tool that allowed non-programmers to prototype independently with a drag-and-drop workflow.

### 🤖 [EspressoBot and MatchaBot](https://github.com/vitorbetmann/sumobot) — Sumo-Fighting Robots:
Two Arduino-based autonomous robots that won me 1st place at both the McMaster and York University 2024 Robot Sumo Competitions, respectively. There was also CappuccinoBot, but we don't talk about it...
